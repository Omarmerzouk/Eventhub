EventHub

Une plateforme de gestion d’événements (conférences, séminaires, workshops) développée en PHP, HTML, CSS et JavaScript. Ce projet permet aux utilisateurs de visualiser, s’inscrire et filtrer des événements, avec système de connexion et d’inscription.

📌 Description

EventHub est une application web full stack qui offre :

🔹 Affichage dynamique d’événements

🔹 Système d’authentification (connexion / inscription)

🔹 Filtrage et recherche d’événements

🔹 Gestion des sessions utilisateur

🔹 Affichage des détails d’un événement

🔹 Interface responsive

Ce projet est idéal comme base pour un site de gestion d’événements ou comme projet d’étude.

🚀 Fonctionnalités

🎟️ Page principale d’affichage des événements

👤 Authentification des utilisateurs

📝 Formulaire d’inscription

🔍 Recherche et filtrage personnalisés

📅 Détails complets pour chaque événement

🛠️ Technologies utilisées

PHP – Backend

MySQL – Base de données (si intégrée)

HTML / CSS – Structure et style

JavaScript – Logique frontend

Ajax / Fetch API – Communication dynamique
